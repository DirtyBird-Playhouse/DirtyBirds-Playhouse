# DirtyBirds-Playhouse — Python dependencies
#
# A stock ComfyUI install already provides: torch, torchvision, numpy, Pillow,
# aiohttp, safetensors, tqdm, kornia, and pyyaml — those are intentionally NOT
# repeated here. Only packages missing from a base ComfyUI are pinned below.
#
# These support the 🖌️ Inpainting node's face-restore pass. The pack degrades
# gracefully without them: the package still loads and the pass is skipped, so
# every other node keeps working.
#
# The Forbidden Vision computer-vision stack (segmentation-models-pytorch,
# ultralytics, opencv-python-headless, scikit-image, timm, onnxruntime) was
# dropped when the Fixer node was retired — face detection and paste-back now
# come from facexlib, which the GAN path already used. Nothing here needs them.

# --- GAN face restore (GFPGAN / CodeFormer) via spandrel ---
# spandrel itself ships with ComfyUI, and is also what loads upscale models.
# GFPGAN comes from its main registry; CodeFormer needs this extra-arch package
# (a pure spandrel arch, no basicsr).
spandrel_extra_arches

# facexlib provides FaceRestoreHelper: 5-point landmark detection + alignment
# to the canonical 512 template and inverse-warp paste-back, so GFPGAN /
# CodeFormer restore angled faces without distorting eyes/mouth.
facexlib
